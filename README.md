# Template Project

This is a full-stack template project using a Monorepo architecture.

## Tech Stack
- **Frontend**: React 18, Vite, React Router v6, Redux Toolkit
- **Backend**: Node.js, Express, Swagger

## Getting Started

1. Install dependencies for all workspaces:
   ```bash
   npm run install:all
   ```

2. Run the development server (starts both frontend and backend):
   ```bash
   npm run dev
   ```

## Folder Structure
- `/backend`: Express server and APIs
- `/frontend`: React application
